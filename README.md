# David Verde Alvarez — Portfolio

Bilingual (EN/ES) portfolio focused on Full-Stack Engineering, AI Automation and Digital Growth.

## Run locally

```bash
npm install
npm start
```

## Production build

```bash
npm run build
```

## Deploy

The project is compatible with Netlify. Connect the GitHub repository and use:

- Build command: `npm run build`
- Publish directory: `build`

## Content

Main portfolio content is centralized in `src/content.js`.
